# Temporal Graph Extraction

Проект извлекает ключевые события, участников и временные метки из текста и формирует на их основе связный граф.

В основе решения лежит предобученная модель RuT5 для суммаризации текста и отдельная seq2seq-модель для преобразования текста в структуру графа. Для обучения используется кастомный детерминированный алгоритм генерации датасета, который учитывает контекстные связи между событиями, в том числе без явных союзов.

## Описание

Задача проекта — автоматически преобразовать текст на русском языке в граф событий, где:
- вершины соответствуют отдельным событиям;
- рёбра описывают связи между событиями;
- временные метки и участники извлекаются из текста и сохраняются в структуре графа.

Проект подходит для анализа новостных, описательных и событийных текстов.

## Что делает система

1. Принимает исходный текст.
2. При необходимости сначала выполняет суммаризацию с помощью RuT5.
3. Передаёт текст в модель извлечения событий.
4. Разбирает результат в структуру вершин и рёбер.
5. Строит интерактивный граф и отображает его в интерфейсе Streamlit.

## Архитектура

Проект состоит из двух основных частей:

### 1. Обучение модели
В ноутбуке `src/rut5_trainer.ipynb`:
- загружается датасет `df_text2graph.jsonl`;
- данные преобразуются в формат seq2seq;
- выполняется обучение модели на базе RuT5;
- обученная модель сохраняется локально.

### 2. Приложение для анализа текста
В файле `src/app.py`:
- загружаются модель суммаризации и модель извлечения событий;
- выполняется pipeline обработки текста;
- результат преобразуется в список вершин и рёбер;
- граф визуализируется через `networkx` и `pyvis`;
- интерфейс реализован на `streamlit`.

## Структура проекта

- `src/app.py` — веб-приложение для анализа текста и визуализации графа.
- `src/rut5_trainer.ipynb` — ноутбук для обучения модели на данных текст → граф.
- `data/df_text2graph.jsonl` — обучающий датасет.

## Формат результата

Система возвращает структуру с:
- `summary` — сжатый текст, если включена суммаризация;
- `nodes` — список вершин с событием, участником и датой;
- `edges` — список рёбер между событиями с типом связи.
